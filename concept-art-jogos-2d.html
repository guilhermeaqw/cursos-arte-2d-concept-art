O que você vai aprender neste curso de Concept Art 2D

Desenvolvido por Guilherme Nogueira, este treinamento guia você pelo pipeline real de criação visual para jogos 2D, desde a blocagem tridimensional com a Tabela Cúbica até o design de personagens, cenários e objetos (props) com storytelling.

  • Compreender os fundamentos do desenho aplicados ao Concept Art para jogos 2D
  • Construir desenhos com formas geométricas 3D, volume e proporção
  • Aplicar luz, sombra, valores tonais e teoria das cores para jogos
  • Utilizar softwares como Photoshop, Krita, Procreate, Clip Studio Paint ou papel
  • Desenvolver um Projeto Final completo de Concept Art para seu portfólio
